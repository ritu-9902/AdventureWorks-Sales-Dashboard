# AdventureWorks Sales & Customer Analytics Dashboard | Power BI

## Project Overview

This project focuses on building an interactive Business Intelligence dashboard using Microsoft Power BI Desktop for AdventureWorks, a fictional global manufacturing company that sells cycling equipment and accessories.

The objective is to transform raw business data into meaningful insights that help management monitor sales performance, analyze customer behavior, evaluate product trends, and understand regional performance.

The project follows an end-to-end Power BI workflow, covering data extraction, transformation, data modeling, DAX calculations, and interactive report development.

## Business Problem

The management team needs a centralized reporting solution to:

- Monitor key business KPIs, including sales, revenue, profit, and returns.
- Compare performance across different regions.
- Analyze product-level sales trends.
- Identify high-value customers.
- Understand customer demographics and purchasing behavior.

## Tools & Technologies

- **Power BI Desktop** – Data visualization and dashboard development.
- **Power Query** – Data cleaning, transformation, and preparation.
- **DAX (Data Analysis Expressions)** – Calculated columns and measures.
- **Data Modeling** – Table relationships and relational data models.
- **Power BI Visualizations** – Interactive charts, cards, tables, maps, and slicers.

## Work Performed

### 1. Data Connection & Transformation
- Connected Power BI to raw CSV files.
- Imported and transformed data using Power Query Editor.
- Applied data cleaning techniques, including handling duplicates, errors, and missing values.
- Used text, numerical, and date transformation tools.
- Created calculated columns and calendar-related fields.
- Used query merging and appending concepts.

### 2. Data Modeling
- Created relational data models.
- Worked with table relationships and key fields.
- Explored relationship cardinality and filter flow.
- Organized data to support meaningful analysis.

### 3. DAX Calculations
- Created calculated columns and measures.
- Worked with business metrics such as total customers, total orders, and revenue per customer.
- Applied DAX calculations to support dynamic reporting and analysis.

### 4. Interactive Dashboard Development
Developed report pages with different visualizations and interactive features, including:

- KPI cards for important business metrics.
- Line charts to analyze customer trends over time.
- Donut charts to understand customer demographics.
- Tables with conditional formatting.
- Top N filters to identify high-value customers.
- Map visuals for geographical analysis.
- Slicers for dynamic filtering.
- Drill-down and drill-through functionality.
- Customized visual interactions.
- Bookmarks and reset buttons for improved report navigation.

## Key Business Analysis Areas

- Customer growth and trends over time.
- Customer segmentation by income level and occupation.
- Identification of top customers based on orders and revenue.
- Revenue per customer analysis.
- Interactive exploration of customer data across different time periods.
